# Roadmap — evidence-first

## Released candidate (this PR)
Portable JSON v0.3, structural validator, human-readable renderer, CONTINUE default, optional non-executing REVIEW and OPEN_FIELD, automated tests.

## Next: only after real-world acceptance
1. Blind cross-model transfer comparison versus plain summaries.
2. Source-backed verification with an explicit human approval step.
3. Optional GitHub/agent adapters, each independently tested and permission-limited.
4. Human-friendly single-click import/export UI, usability tests and accessible design.
5. Evaluate temporal memory providers only when a measured need exists.

## Marketing boundary
No claim of 'best on GitHub', universal compatibility, guaranteed security or adoption before evidence. Publish reproducible benchmarks and user feedback. No automated spam, fake reviews, or manipulated downloads.
