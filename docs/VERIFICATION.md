# Verification levels

- L0: file parses and required fields exist. **Automated** by the v0.3 CLI.
- L1: obvious malformed values and selected credential signatures detected. **Partial** automated validation; NOT comprehensive privacy/security screening.
- L2: source URLs, commit SHAs, timestamps and permissions independently verified. **Manual**.
- L3: independent recipient reconstructs goal, decisions, constraints and next action against a source-grounded answer key. **Not yet tested**.
- L4: recipient completes a bounded authorized task and passes acceptance checks. **Not yet tested**.

A passing CLI run is not evidence of L2–L4. No claims of security certification, verified facts or real-world superiority are justified by structural tests.
